# LXFM-1

**Dub techno drum machine firmware for the M-VAVE FM-1**, by **Narti Live**.

Website: https://narti-live.github.io/lxfm-1/
Instagram: https://www.instagram.com/narti_live/ · YouTube: https://youtube.com/@narti_live

## What it does

- **8 voices for dub techno:** a kick tuned only between 43 and 55 Hz with a MORPH knob from 808 boom to 909 punch, a low 808 tom, a dub chord stab (an 808 clave ringing a minor 7th through a band-pass), and 808 / 909 snare, ride, closed hat, open hat and clap. Every voice is mixed to a fixed level, so it is safe to play live.
- **No menu diving:** black keys pick the voice, white keys are its 16 steps. Keys flash on hits; muted voices blink fast.
- **Randomisers that stay in style:** OCT- new sound, OCT+ new pattern, POLY = MUTATE (small changes, never the kick), last black key = RANDOM ALL.
- **Dub effects ready at power-on:** dotted-1/8 delay, spring reverb, swing, kick ducking.
- **99 patterns:** SAVE, LOAD, DELETE. A pattern holds everything.
- **MIDI out over USB:** BOTH or SEQ (silent sequencer) in the Vermona DRM1 MKIV's order and notes, channel 10.
- **Android app** (LXFM-1 Control): all steps on one screen, mutes, dice.

## Install

1. Download `downloads/LXFM-1-1.4.fwsc`.
2. Flash it with M-Flasher+, like an official update.
3. To go back, flash M-VAVE's official firmware the same way.

Install at your own risk. Not made or supported by M-VAVE.
