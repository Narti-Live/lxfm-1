Flash LXFM-1

Install LXFM-1 1.4 on your FM-1 straight from this page, over the USB cable. It takes a few minutes.

  1. Use Chrome or Edge on a computer

    The page talks to the FM-1 over Web MIDI, which these browsers support.

  2. Connect the FM-1

    Use a USB data cable straight to the computer. Close other apps that use MIDI.

  3. Install

    Keep the cable in and this page open until it says Done. The FM-1 restarts by itself. When the browser asks, allow MIDI (SysEx) access.

    Loading the firmware…

You install LXFM-1 at your own risk. To go back, flash M-VAVE's official firmware with M-UPGRADE (www.m-vave.com/download). If the FM-1 stops answering, see the recovery guide.
